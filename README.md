# SA預約

[下載最新版](https://github.com/hsiao840412/SA-Booking/releases/latest)

- 支援 macOS 26 或更新版本、Apple Silicon（M 系列）Mac。
- 開啟 DMG，將「SA預約」拖到「應用程式」。
- App 內可手動檢查更新；自動檢查間隔為 12 小時。
- 此版未經 Apple 公證。首次被阻擋時，依 [Apple 說明](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)，在「系統設定 → 隱私權與安全性」確認開啟。
